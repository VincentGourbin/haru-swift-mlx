Conversions (à porter telles quelles, plan calculé par noms et formes, sans MLX) :
- **Fusion** par concaténation sur l'axe 0, dans cet ordre :
  `linear_attn.in_proj` ← `in_proj_qkv, in_proj_z, in_proj_b, in_proj_a` ;
  `self_attn.qkv` ← `q_proj, k_proj, v_proj` (q_proj contient déjà [query, gate] par tête) ;
  `mlp.gate_up` ← `gate_proj, up_proj` ;
  `head.ada` ← `head.layers.{0..3}.ada`, puis `head.final.ada`.
- **GAMMA** : `lm.norm`, `*_layernorm`, `self_attn.{q,k}_norm` → fp32 `1 + w`.
- **CHANNELS_LAST** : `linear_attn.conv1d.weight` `[out, in, k]` → `[out, k, in]` (`transpose(0, 2, 1)`, `loaders._convert`).
- **CONV_MATRIX** : convolutions du codec (stem, head, down.i, stages.i.j.conv) `[out, in, k]` →
  `[out, k·in]` (`transpose(0, 2, 1)` puis reshape : taps côte à côte ; filtres depthwise `[C, 1, 7]` → `[C, 7]`).
- **CONV_TRANSPOSE_MATRIX** : `codec.decoder.up.i` `[in, out, k]` → `[out·k, in]` (`transpose(1, 2, 0)` puis reshape). Puis cast au dtype demandé (sauf GAMMA/SCALAR, fp32).
- **SCALAR** : `latent_scale`, `latent_bias` → fp32 scalaires.
- `check_plan` : chaque paramètre attendu présent, aucun en trop, formes exactes — sinon erreur
  listant les 20 premiers écarts.

Chargement : tenseur par tenseur, `eval` par partie, jamais `eval(model.parameters())` global ;
la conversion ne doit pas doubler transitoirement les 10,5 Go (pic à mesurer, `plan/03-budget.md`).
