# 2.1 L'architecture, trame par trame (`haru_mlx/models/haru.py`, `session.py`)

Une position du modèle de langage = une trame de 133 ms (3200 échantillons à 24 kHz, 7,5 Hz).

```
entrée position t :  embed(text[t]) + model_audio_proj(scale(model_latent[t]))
                                    + user_audio_proj(scale(user_latent[t]))
backbone (32 couches, cache)  → hidden[t]  (après la norme finale)
hidden[t] → logits (embedding liée)          → text[t+1]   (échantillonné)
hidden[t] → tête MeanFlow (1 pas, bruit)      → model_latent[t+1] → décodeur codec → 3200 éch.
```

- `scale_latents(raw) = (raw + latent_bias) * latent_scale` en fp32 (deux scalaires du
  checkpoint) ; `unscale` à la sortie de la tête : `z / latent_scale - latent_bias`.
- `AudioProjector` : `fc2(RMSNorm(fc1(x)))` (eps 1e-6, gain bf16 **non** recentré), avec biais.
- Masques : la carte n'a ni audio modèle ni audio utilisateur ; la référence de voix a l'audio
  modèle seul. Le masque multiplie la projection (pas l'entrée).
- Session : `start()` exécute le prompt par tranches de 512 positions, puis `_emit(hidden)` donne
  la trame 0. Ensuite `step(user_frame t)` : encode la trame utilisateur (latent **échantillonné**
  autour de la moyenne : `codec.sample`), forme la position `token[t] + latent[t] + user[t]`,
  avance d'une position, `_emit` → trame t+1. Le modèle a toujours exactement une trame d'avance :
  133 ms est la seule latence structurelle.
- `feed(audio)` : le micro peut livrer l'audio par blocs quelconques ; l'avant de l'encodeur tourne
  dessus au fil de l'eau, `step()` sans argument finit la trame quand `frames_ready > 0`.
- `_emit` : logits → DRY → logits PAD/EOP recalculés en fp32 → biais EOP → (speak_first : PAD,
  EOP, EOS interdits une trame) → top-k 25 / T 0,7 → jeton ; bruit normal → tête (guidance 1,5)
  → unscale → décodage codec → `clip(-1, 1)` ; **un seul `eval`** de tout (jeton, latent, audio,
  caches) ; puis `.item()` du jeton pour DRY et détokenisation.
- Aléa : une clé MLX par session, `split` à chaque tirage (`_next_key`), jamais l'état global.
