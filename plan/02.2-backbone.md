# 2.2 Backbone Qwen3.5-4B (`haru_mlx/models/qwen3_5.py`, `gated_delta.py`)

32 couches, hidden 2560, vocab 248 320, `layer_types` : 3 Gated DeltaNet puis 1 attention, ×8.
Chaque couche : `h = x + mixer(input_layernorm(x))` ; `out = h + mlp(post_attention_layernorm(h))`.
Norme finale `lm.norm` puis logits par `embed_tokens.as_linear` (embedding liée).

## RMSNorm du backbone
`mx.fast.rms_norm(x.float32, weight, eps).astype(x.dtype)` avec `weight` **fp32 = 1 + w** (le
checkpoint stocke `w` centré sur 0). Vaut pour `input_layernorm`, `post_attention_layernorm`,
`q_norm`, `k_norm`, `lm.norm` (pas pour la `GatedNorm` ni les projecteurs audio).

## MLP
`gate_up` (2 × 9216 lignes, gate puis up) → `down_proj(silu(gate) * up)`.

## Gated DeltaNet (24 couches)
- `in_proj` fusionné : lignes `qkv` (conv_dim 8192) | `z` (4096) | `b` (32) | `a` (32).
- Convolution causale depthwise noyau 4 sur `qkv`, état = 3 dernières entrées, puis `silu`.
- q, k : 16 têtes × 128 ; v : 32 têtes × 128 (une tête de clé sert 2 têtes de valeur).
- `q = scale² · rms_norm(q, eps')`, `k = scale · rms_norm(k, eps')`, `scale = 128^-0.5`,
  `eps' = 1e-6 · scale²` (rms_norm sans gain = normalisation L2 remise à l'échelle).
- `beta = sigmoid(b)` ; `decay = exp(-exp(A_log.f32) · softplus(a.f32 + dt_bias))` en fp32.
- Récurrence : `S = g·S ; S += (beta·(v − S k)) kᵀ ; y = S q`, état `[B, 32, 128, 128]` **fp32**.
  Noyau Metal amont (une SIMD-group par ligne d'état, `Dk/32` éléments par fil) + repli tableau.
- `GatedNorm` : `rms_norm(y, weight)` (gain bf16 non recentré) puis `silu(z.f32) * normed` en fp32,
  retour au dtype ; `out_proj`.

## Attention (8 couches)
- `qkv` fusionné : par tête `[query 256, gate 256]` (16 têtes), puis k (4 × 256), puis v (4 × 256).
- `q_norm`, `k_norm` (RMSNorm 1 + w) par tête, **avant** RoPE.
- RoPE `nn.RoPE(64, base 1e7)` — non entrelacée (traditional = false), sur les 64 premières
  dimensions ; les sections MRoPE [11, 11, 10] se réduisent à une RoPE 1-D pour du texte seul.
- SDPA (scale 256^-0.5), masque causal seulement si T > 1 ; sortie `o_proj(att · sigmoid(gate))`.
- `KVCache` préalloué par blocs de 256 positions, écriture en place.

## Chemins
Une position (trame vivante) : chaque couche GDN est **une** fonction compilée avec l'état en
entrée/sortie explicites ; l'attention compile l'avant-cache (`_project`) et l'après-cache
(`_finish`). Positions multiples (prompt) : mêmes poids, chemin non compilé. À re-compiler après
quantification (les closures capturent les poids).
